# Hisse Robotu V1.0 — Kullanım Kılavuzu

## Başlatma
Proje klasöründe şu komutu çalıştırın:

.\Hisse-Robotu-Baslat.ps1

## Kapatma
Programın çalıştığı terminalde Ctrl+C tuşlarına basın.

## Kurulum
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt

## Uyarı
Programın ürettiği sonuçlar yatırım tavsiyesi değildir.
